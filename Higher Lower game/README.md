# 🔼 Higher Lower Game Project

An arcade-style comparison game where players guess which famous account has a higher social media follower count.

## 📖 Overview
The game presents two accounts from a dataset (musicians, athletes, brands, actors). Players pick whether Account B has a higher or lower follower count than Account A. Correct guesses keep the game streak alive.

## 🚀 How to Run
```bash
python higher_lower_game.py
```

## ✨ Features
- Extensive dictionary dataset of global figures and platforms.
- Duplicate comparison prevention logic.
- Input sanitation and continuous score tracking.
