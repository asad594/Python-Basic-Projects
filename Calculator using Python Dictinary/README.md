# 🧮 Dictionary Calculator Project

An interactive arithmetic calculator powered by Python dictionary dispatch mapping.

## 📖 Overview
Instead of traditional `if/elif` chains, this project demonstrates first-class functions in Python by mapping operators (`+`, `-`, `*`, `/`) directly to function references inside a dictionary data structure.

## 🚀 How to Run
```bash
python main.py
```

## ✨ Features
- Continuous calculations using accumulated results.
- `ZeroDivisionError` handling.
- Input parsing and validation.
