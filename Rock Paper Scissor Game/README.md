# 🪨 Rock Paper Scissors Game Project

A classic CLI arcade implementation of Rock Paper Scissors with ASCII art illustrations.

## 📖 Overview
Play against an automated random computer player. Choice zero corresponds to Rock, one to Paper, and two to Scissors. Continuous session score tracking accumulates wins and losses.

## 🚀 How to Run
```bash
python main.py
```

## ✨ Features
- Hand gesture ASCII graphics representation.
- Session score counter.
- Input validation for choices outside range `[0, 2]`.
