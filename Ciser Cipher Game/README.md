# 🔏 Caesar Cipher Project

A text encryption and decryption tool leveraging substitution cipher principles.

## 📖 Overview
The Caesar Cipher shifts letters in the alphabet by a user-defined integer offset key. Non-alphabetic characters (spaces, punctuation, digits) and letter casing are preserved during encoding and decoding.

## 🚀 How to Run
```bash
python ciser_cipher_game.py
```

## ✨ Features
- Flexible integer shift keys (handles shifts larger than 26 via modulo operations).
- Case and symbol preservation.
- Both `encode` and `decode` transformation modes.
