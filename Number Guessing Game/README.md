# 🎯 Number Guessing Game Project

A numbers-based guessing game with difficulty level presets and directional feedback.

## 📖 Overview
The application picks a secret integer between 1 and 100. Players select between 'easy' (10 turns) and 'hard' (5 turns) modes and guess until finding the target number or exhausting turns.

## 🚀 How to Run
```bash
python main.py
```

## ✨ Features
- Difficulty level selection (`Easy` = 10 turns, `Hard` = 5 turns).
- Directional hint indicators (`Too High` / `Too Low`).
- Integer input sanitation and replay capability.
