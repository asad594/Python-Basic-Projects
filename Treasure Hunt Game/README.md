# 🗺️ Treasure Hunt / Island Game Project

An interactive text-driven choose-your-own-adventure story written in Python.

## 📖 Overview
Navigate through cross roads, mysterious lakes, multi-colored doors, ancient riddles, and underground caverns to reach the hidden legendary treasure.

## 🚀 How to Run
```bash
python main.py
```

## ✨ Features
- Detailed ASCII treasure landscape banner.
- Branching story paths with distinct victory and defeat outcomes.
- Case-insensitive string parsing (`left`, `right`, `wait`, `swim`, door colors).
