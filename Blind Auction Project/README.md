# 🏷️ Blind Auction Project

A secret bidding system built with Python dictionary mapping logic.

## 📖 Overview
The Blind Auction application allows multiple users to enter secret bids sequentially. After all users submit their bids, the application evaluates the dictionary to automatically announce the winner.

## 🚀 How to Run
```bash
python blind_auction.py
```

## 💡 Key Features
- Input validation for numeric bid amounts and non-empty names.
- Screen spacing between bidders for secrecy.
- Automatic max value evaluation across stored dictionary bids.
