# 🃏 Blackjack (Black Jackson Project)

A CLI implementation of the classic Blackjack casino card game in Python.

## 📖 Features
- **Aces Handling:** Automatically converts Ace value between 11 and 1 when total hand score exceeds 21.
- **Natural Blackjack:** Detects 2-card 21 totals instantly.
- **Dealer AI:** Computer dealer draws additional cards on totals less than 17.
- **ASCII Art UI:** Terminal banner and clear score presentation.

## 🚀 How to Run
```bash
python Black_jackson_project.py
```

## 🎮 Rules
1. Get as close to 21 as possible without exceeding 21.
2. Aces count as 11 or 1 depending on whether hand total exceeds 21.
3. Face cards (Jack, Queen, King) count as 10.
