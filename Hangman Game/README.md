# 💀 Hangman Game Project

An interactive terminal word-guessing game with dynamic ASCII gallows art updates.

## 📖 Overview
Players attempt to guess a hidden random word one letter at a time within 6 life attempts. Each incorrect guess builds another stage of the gallows figure.

## 🚀 How to Run
```bash
python hangman.py
```

## ✨ Features
- Extensive dictionary of challenging words.
- Single letter input validation and repeat guess detection.
- ASCII art gallows state rendering.
